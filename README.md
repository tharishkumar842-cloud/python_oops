# Python and Machine Learning Practice

## About
This repository contains my Python practice projects as I learn object-oriented programming, NumPy, and machine learning using Scikit-learn.

## Projects

### 1. Customer Purchase Prediction
**File:** `customer_purchase_prediction.py`

Uses a Random Forest Classifier to predict whether a customer will purchase a product based on customer information and website activity.

**Features:**
- Creates a dataset using Pandas
- Splits data into training and testing sets
- Trains a Random Forest model
- Evaluates accuracy, classification report, and confusion matrix
- Predicts purchases for new customers
- Displays prediction probabilities and feature importance

**Libraries:** Pandas, Scikit-learn

### 2. Feature Scaling with NumPy
**File:** `feature_scaler.py`

Uses a Python class and NumPy to perform feature scaling on numerical data.

**Features:**
- Calculates dataset shape, mean, and standard deviation
- Performs Min-Max scaling
- Performs standardization using Z-scores
- Practices classes, methods, and NumPy array operations

**Library:** NumPy

## Requirements
- Python 3
- NumPy
- Pandas
- Scikit-learn
