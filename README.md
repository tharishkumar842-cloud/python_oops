# Python Object-Oriented Programming (OOP) Practice

This directory contains examples demonstrating Python OOP concepts, specifically focusing on classes, inheritance, constructor initialization, and method overriding.

## Contents

* **`class_practice.py`**: Basic class definition (`laptop`) with attributes and a display method.
* **`employee.py`**: Basic class (`employee`) demonstrating attribute initialization and a display function.
* **`developer.py`**: Inheritance example showing a subclass (`developer`) inheriting from a parent class (`employee`) and extending functionality using `super().__init__()`.
* **`override_init.py`**: Demonstration of method overriding where a subclass (`dev`) overrides a method (`work`) defined in its parent class (`emp`).
