# Python OOP Practice

## About
This repository contains my Python Object-Oriented Programming (OOP) practice programs. These projects help me understand classes, objects, constructors, inheritance, and method overriding.

## Projects

### 1. Laptop Class
**Concepts:** Classes, objects, constructors, instance attributes, and methods.

Creates a `laptop` object with brand, price, and processor information and displays its details.

### 2. Employee and Developer
**Concepts:** Inheritance, `super()`, constructors, and methods.

Creates an `employee` parent class and a `developer` child class. The developer inherits the employee's name and adds a programming language. It demonstrates code reuse through inheritance.

### 3. Employee Details
**Concepts:** Classes, objects, constructors, and instance attributes.

Creates an employee object with a name and salary, then displays the employee's information.

### 4. Method Overriding
**Concepts:** Inheritance, `super()`, and method overriding.

Creates an `emp` parent class and a `dev` child class. The developer overrides the parent's `work()` method to display a message specific to the developer.

## Technologies
- Python 3

## How to Run
Run each Python file separately:

```bash
python filename.py
```

Replace `filename.py` with the name of the Python file you want to execute.

## Learning Outcomes
- Understanding classes and objects
- Using constructors with `__init__()`
- Working with instance attributes and methods
- Implementing inheritance
- Using `super()` to call a parent constructor
- Practicing method overriding
