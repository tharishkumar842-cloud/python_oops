# Simple Dataset Programs with NumPy

## Description
This repository contains 4 beginner-friendly Python programs using **NumPy**.  
These programs help to  learn about arrays, classes, and basic data operations.

---

## Program 1: Basic Dataset
- Converts a list into a NumPy array
- Displays the dataset
- Calculates **sum**, **mean**, and **shape**

## Program 2: Extended Dataset
- Works with a NumPy array
- Finds **sum, mean, shape, min, max**
- Calculates **row-wise sum** and **column-wise sum**

## Program 3: Dataset Handler
- Counts **rows** and **columns**
- Finds **mean, max, min** of each column
- Uses class methods for structured data handling

## Program 4: Data Scaling
- Converts list to NumPy array
- **Displays dataset**
- Performs **Min-Max Scaling**
- Performs **Standardization**
