# Python OOP Examples

This repository contains simple Python programs to understand
Object-Oriented Programming (OOP) concepts.

## Programs Included

### 1. Car Class
- Uses a class with brand and year
- Demonstrates constructor and methods
- Creates multiple car objects

### 2. Employee Class
- Shows class variables and instance variables
- Displays employee name, salary, and company name
- Uses multiple objects

### 3. Student Class
- Simple class with name and roll number
- Uses constructor and method to display details

## Concepts Covered
- Classes and Objects
- __init__ constructor
- Instance variables
- Class variables
- Methods
